Privacy Policy

Last updated: November 17, 2026

MysteryVerse is a personal YouTube video automation project.

Information and Services

The project uses Google OAuth and the YouTube Data API to upload videos to the owner's YouTube channel. It may use the Gemini API to generate video scripts.

Data Handling

Google authorization credentials and API keys are stored as GitHub Actions secrets. They are used only to operate the project and are not intentionally shared publicly.

Third-Party Services

Google, YouTube, GitHub and Google Gemini may process information according to their own privacy policies and terms.

Data and Access

The channel owner can revoke the project's Google access through their Google Account security settings.
